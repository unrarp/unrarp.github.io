# Personal website

My personal website, served by GitHub Pages at https://unrarp.github.io. Plain HTML and CSS with no build step (`.nojekyll` turns off GitHub's Jekyll build); the design is adapted from the [Compass](http://excentris.github.io/compass/) Jekyll theme.

To preview locally, run `python3 -m http.server` in this directory and open http://localhost:8000.
